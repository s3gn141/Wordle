#Wordly

Игра в слова с графическим интерфейсом на Python.

Смысл игры: отгадать слово из 5 букв, подбором других слов, для букв которых будет выводиться информация
о их нахождении в загаданном слове.

Правила:
Количество попыток на отгадку ограничено(по-умолчанию их 6).Слова состоят только из английских букв.
Допустимые слова взяты из заранее подготовленных словарей(ссылка на них в конце файла). При отгадке буквы могут иметь 
3 разных цвета: 
- зеленый - означает что буква находится на правильном месте в загаданном слове; 
- желтый - означает что буква находится в загаданном слове но расположена в неправильном месте;
- серый - означает что буквы в загаданном слове нет.


Требования:
Версия python 3.10+
tkinter уже входит в стандартную библиотеку, отдельно ставить не нужно.

Установка:
1) Склонируйте или скачайте проект
2) Откройте его через любой компилятор(рекоменд. Vs Code)
3) Создать виртуальное окружение (python -m venv .venv)
4) Активируйте его (
   - macOS / Linux: source .venv/bin/activate
   - Windows: .venv\Scripts\activate
   )
5) Установить зависимости из requirements.txt (pip install -r requirements.txt) (Сейчас в requirements.txt только pytest, он нужен для тестов.)

Запуск:
Из корневой папки проекта, с активированным окружением: python main.py

Процесс игры:
- Буквы вводятся с клавиатуры (только английская раскладка).
- Backspace стирает последнюю букву.
- Enter отправляет слово.
- Если слово слишком короткое, содержит недопустимые символы или отсутствует в словаре, над полем появится сообщение, и попытка не будет потрачена.
- В конце игры над полем показывается сообщение о победе или о поражении (в этом случае с загаданным словом).
- Чтобы начать новую игру, перезапустите программу.

Тесты: 
Из корневой папки: pytest
Тесты проверяют ключевую логику: сравнение догадки с загаданным словом (включая повторяющиеся буквы), загрузку и фильтрацию словаря, правила игры (победа, поражение, некорректный ввод).

Словари:
В папке data/ лежат два списка слов:

- answers.txt: слова, из которых выбирается загаданное;
- allowed.txt: слова, которые принимаются как догадки.

Репозиторий откуда взяты: (https://gist.github.com/cfreshman/dec102adb5e60a8299857cbf78f6cf57)

Структура проекта

├── game.py            # состояние партии и правила игры
├── checker.py         # сравнение догадки с загаданным словом
├── words.py           # загрузка словарей, выбор секретного слова
├── data/
│   ├── answers.txt    # слова-ответы
│   └── allowed.txt    # допустимые слова
├── tests/             # тесты на pytest
├── pytest.ini         # настройки pytest
├── requirements.txt   # зависимости
└── README.md
